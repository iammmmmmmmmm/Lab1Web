\# Praktikum HTML Dasar



\## Deskripsi



Praktikum ini merupakan latihan dasar HTML pada mata kuliah Pemrograman Web.

Pada praktikum ini dilakukan beberapa percobaan menggunakan tag-tag dasar HTML,

seperti heading, paragraf, formatting teks, gambar, hyperlink, list, dan struktur

konten halaman web.



\---



\## 1. Membuat Paragraf HTML



Pada tahap pertama, dibuat sebuah halaman HTML sederhana yang berisi teks

mengenai pembelajaran HTML dasar. Pada tahap ini digunakan tag paragraf

untuk menampilkan teks pada halaman web.



!\[Foto 1](image/foto1.png.png)



\---



\## 2. Menambahkan Heading



Pada tahap kedua, ditambahkan heading atau judul pada halaman HTML.

Heading digunakan untuk membuat judul dengan ukuran yang berbeda sesuai

dengan tingkatannya.



Pada contoh ini digunakan judul \*\*"Belajar Dasar HTML"\*\* dan subjudul

\*\*"Paragraf pada HTML"\*\*.



!\[Foto 2](image/foto2.png.png)



\---



\## 3. Formatting Teks



Pada tahap ketiga, dilakukan formatting atau pemformatan teks.

Beberapa bagian teks dibuat memiliki format tertentu, seperti teks miring,

garis bawah, dan penekanan pada kata tertentu.



Formatting digunakan agar informasi tertentu pada halaman lebih mudah

diperhatikan oleh pengguna.



!\[Foto 3](image/foto3.png.png)



\---



\## 4. Menambahkan Gambar



Pada tahap keempat, ditambahkan sebuah gambar ke dalam halaman HTML.

Gambar digunakan untuk membuat halaman web menjadi lebih informatif dan

menarik.



Gambar ditampilkan menggunakan tag `<img>` pada HTML.



!\[Foto 4](image/foto4.png.png)



\---



\## 5. Menambahkan Hyperlink



Pada tahap kelima, ditambahkan beberapa hyperlink pada halaman.

Hyperlink digunakan untuk menghubungkan halaman dengan halaman lain atau

website eksternal.



Pada contoh ini terdapat beberapa tautan seperti \*\*Dasar HTML\*\*,

\*\*Halaman 2\*\*, dan \*\*Website Eksternal\*\*.



!\[Foto 5](image/foto5.png.png)



\---



\## 6. Membuat Unordered List



Pada tahap keenam, dibuat daftar menggunakan unordered list.

Unordered list digunakan untuk menampilkan daftar yang tidak membutuhkan

urutan angka.



Contohnya adalah daftar keahlian:



\- HTML

\- CSS

\- JavaScript



!\[Foto 6](image/foto6.png.png)



\---



\## 7. Membuat Ordered List



Pada tahap ketujuh, dibuat daftar menggunakan ordered list.

Ordered list digunakan untuk menampilkan daftar yang memiliki urutan angka.



Contohnya adalah urutan pembelajaran:



1\. Mempelajari struktur HTML

2\. Mempelajari tag dan atribut

3\. Membuat halaman HTML

4\. Menguji halaman pada browser



!\[Foto 7](image/foto7.png.png)



\---



\## 8. Membuat Profil Mahasiswa



Pada tahap terakhir, ditambahkan bagian profil mahasiswa pada halaman HTML.

Bagian ini digunakan untuk menampilkan informasi atau daftar yang berkaitan

dengan profil mahasiswa.



!\[Foto 8](image/foto8.png.png)



\---



\## Kesimpulan



Dari praktikum ini dapat dipelajari beberapa tag dasar HTML yang digunakan

untuk membuat struktur dan isi halaman web. Tag yang dipraktikkan meliputi

heading, paragraf, formatting teks, gambar, hyperlink, unordered list,

dan ordered list.



Praktikum ini memberikan pemahaman dasar mengenai cara HTML menyusun

konten yang kemudian ditampilkan oleh browser.
